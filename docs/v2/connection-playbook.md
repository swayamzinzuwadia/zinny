# Connecting a direct institute's website

These are the steps the Zinny team follows for each institute, starting with the first pilot. The Integration desk tracks them.

1. **Discovery call.** Record how the site is built (WordPress, custom, site builder), which gateway it uses, what it collects at sign-up, how products are named, and whether a developer is available.
2. **Create the institute** on the Direct plan and invite its admin.
3. **Set up the catalogue in Zinny**: departments, courses, batches, fees, student ID format.
4. **Pick the connection**: plugin for WordPress, API for a custom site, gateway listener when there is no developer.
5. **Issue test keys.** The site sends test sign-ups and orders. Check them in the sync monitor.
6. **Map products** to courses and batches and set placement rules.
7. **Add the "Go to my classes" button** to the site's account page and test the handoff.
8. **Load existing students**: a CSV with the site's IDs, so earlier students match later orders.
9. **Reconcile one week** of test data: counts on the site against counts in Zinny.
10. **Go live**: switch to live keys, watch the first real orders, hand the Arrivals list to the institute's staff.
11. **After launch**: weekly reconciliation for a month, then alerts only.
