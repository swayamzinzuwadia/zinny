# Glossary

Terms used in the Zinny platform feature reference.

| Term | Meaning |
|---|---|
| Account Manager | Zinny team role that manages institutes and licences and reads content flags |
| Auto-renew | A licence setting. When on, the daily billing job renews the licence and invoices the next term, within the renewal lead time before it ends |
| Breach register | The Zinny team's log of personal data breaches, with live 72-hour countdowns |
| Caps | The most students and staff a licence allows. Seat packs raise them. The app warns at 90% and 100% but does not block |
| CGST, SGST, IGST | The GST lines on an invoice. CGST and SGST (half each) apply within one state, IGST across states. The total is the same |
| Choose-plan page | The institute admin page where a trial or frozen institute picks and pays for a plan |
| Consent record | One stored row per person and purpose, with the notice version, times and source |
| Content flag | A note from Content QA that a course has a problem, such as a misleading claim. It stays open until resolved |
| Data console | A Super Admin view of every database table with create, read, update and delete |
| Data Fiduciary | The party that decides why and how personal data is used. The institute for its learners, Zinny for marketplace learners |
| Data Processor | The party that handles data for a fiduciary. Zinny is the processor for institutes |
| DPDP | India's Digital Personal Data Protection Act 2023 and its 2025 Rules |
| Erasure | Removing a person's personal data on request. Invoices and the consent log are kept |
| Freeze | The state of a self sign-up institute whose trial ended without a plan. Admins can only choose a plan. Everyone else sees a "paused" page. Nothing is deleted |
| GSTIN | The 15-character GST registration number. The first two digits are the state code |
| Guardian consent | A parent's or guardian's confirmation for a learner under 18, given through a 7-day link |
| Impersonation (Sign in as) | A Super Admin signs in as another person for up to 2 hours, with a banner and a log |
| Institute | An organisation on Zinny with its own private space. The code also calls it a university or tenant |
| Institute Admin | The highest role inside one institute |
| Licence | The record of an institute's plan, caps, modules, term, price and renewal. Each institute has at most one |
| Licence-end reminder | An email and notification to institute admins at 30, 14, 7 and 1 days before the licence ends |
| Marketplace | The shared space where learners buy courses from many institutes |
| Paise | One hundredth of a rupee. Zinny stores all money as whole paise |
| PAN | Permanent Account Number. The one document needed to start a trial |
| Plan | A priced package: caps, modules, billing period and GST rate. Pilot, Standard and Enterprise come built in |
| Rights request | A request by a person to download, correct, erase, nominate or complain about their data |
| RLS (row-level security) | A database rule that lets each institute's connection see only its own rows |
| Seat pack | An add-on that raises a licence's cap by 25 students or 5 staff by default, priced for the time left in the term |
| Sign-ups | The panel page for institutes that signed themselves up, with document review and trial extension |
| Super Admin | The Zinny team role with every permission. Only it manages the team, people, data and impersonation |
| Support mode | A Zinny team member enters an institute as an Institute Admin for up to 120 minutes, with a reason, logged |
| Suspension | A manual block by the Zinny team. The institute's people cannot sign in and their work is kept |
| System actor | The identity jobs use when they run for one institute |
| Trial | A 3-day free period after self sign-up, with a countdown banner |
| View as | A Super Admin sees a student's screens read-only |
